## Projects

The projects below were completed for my Computer, Sound, and Music course. They focus on digital audio, waveform generation, sound synthesis, and audio signal processing.

## [Clipped](https://github.com/Pete-Treemeth-portfolio/clipped)

A digital audio processing project focused on waveform manipulation and clipping. This project helped me practice working with audio samples and understanding how changes to a waveform affect the resulting sound.

## [Modem](https://github.com/Pete-Treemeth-portfolio/modem)

A Bell 103-style demodulator that decodes text messages from audio using frequency shift keying. This project focused on analyzing audio signals and identifying the frequencies used to represent binary data.

## [Aleatoric](https://github.com/Pete-Treemeth-portfolio/Aleatoric)

A random music generator that creates short songs using randomly selected song structures, chord loops, keys, tempos, and melody notes. The program generates sawtooth waves and can either play the song directly or write it to a WAV file.

## [Synth](https://github.com/Pete-Treemeth-portfolio/synth)

A monophonic software synthesizer that plays notes using a sawtooth wave and a fixed attack-release envelope. Since I did not have a physical MIDI controller, the program uses an aleatoric software controller to generate MIDI-style note on and note off events.
